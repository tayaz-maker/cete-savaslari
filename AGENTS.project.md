# TarikLab — project instructions

Active product: **www.tariklab.com** (this repo). Native/Godot is **paused**.

1. TarikLab games will later ship as **standalone downloadable games**, not one giant native TarikLab app.
2. Do **not** continue native Godot work (`tariklab-app`) unless the product owner explicitly restarts it.
3. The website is the active development surface. Web work does not wait for native.
4. After every **meaningful** website change, append [`docs/WEB_APP_SYNC_LEDGER.md`](docs/WEB_APP_SYNC_LEDGER.md).
5. **Web ↔ Native Content Parity** is binding. Shared artwork/content lives in private `tayaz-maker/tariklab-content`; web and native bundle copies.
6. **Audio remains disabled.**
7. Never remove existing website games, content, data, or routes because of native work. Do not change gameplay just to create parity.
